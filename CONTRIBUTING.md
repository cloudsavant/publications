# Contributing

Thank you for contributing a publication! Follow the steps below to add your markdown-based article.

## Steps

1. **Fork** this repository and create a feature branch.
2. **Create a directory** under `publications/` with a short, URL-friendly slug that describes your publication.  
   Example: `publications/intro-to-cloud-computing/`
3. **Add a `README.md`** inside that directory. Use the template below as a starting point.
4. **Open a pull request** against the `main` branch with a brief description of your publication.

## Publication Template

```markdown
# Title of Your Publication

**Author:** Your Name  
**Date:** YYYY-MM-DD  
**Tags:** tag1, tag2

---

## Abstract

A short summary of the publication.

## Introduction

...

## Conclusion

...

## References

- Reference 1
- Reference 2
```

## Guidelines

- Write in clear, concise English.
- Use standard Markdown syntax.
- Include a meaningful title, author, and date in the front matter.
- Keep images and other assets inside the publication directory (e.g. `publications/my-article/images/`).
- One publication per directory; do not mix multiple articles in the same folder.
