### LLMs as Infrastructure

**File**: [post-01-llms-as-infrastructure.md](./post-01-llms-as-infrastructure.md)

**LinkedIn Post**: [View original post](https://www.linkedin.com/posts/tibor-varga-4830b453_aiengineering-llm-mlops-share-7434597997012783105-SRtw?utm_source=share&utm_medium=member_desktop&rcm=ACoAAAs6CKMBEzsUKTWAHXZq0qnvrqfEDVPZzRk)

**Summary**: An architectural pattern for treating LLM providers as pluggable infrastructure backends rather than hardcoded dependencies. Covers practical implementation patterns from production systems, multi-environment strategies, and the discipline of treating model providers as infrastructure.

**Key Topics**:
- Provider abstraction patterns
- Multi-environment LLM strategies (local/CI/production)
- Cost optimization and vendor lock-in prevention
- Factory pattern implementation for model providers
