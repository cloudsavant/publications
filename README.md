# Publications

A collection of markdown-based publications covering various topics.

## Structure

```
publications/
└── <slug>/
    └── README.md   # The publication content
```

Each publication lives in its own subdirectory under `publications/` and is written in Markdown.

## How to Add a Publication

1. Create a new directory under `publications/` using a short, descriptive slug (e.g. `publications/my-article/`).
2. Add a `README.md` file inside that directory with the publication content.
3. Open a pull request with your changes.

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.
